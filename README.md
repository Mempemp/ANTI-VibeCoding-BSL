## 📋 Правила, скиллы и знания

### 1. [ai_rules_1c](https://github.com/comol/ai_rules_1c)

Обширный набор правил, скиллов и описаний субагентов. Репозиторий от амбассадора кодинга с ИИ на 1С — **comol**. Активно развивается и обновляется.

> ⚠️ Ориентирован на использование собственных MCP от comol. Если не приобретаете их сервера — ищите аналогичные опенсорсные решения.

**📺 Видео-инструкция по обновлению:** [https://rutube.ru/video/122e0f05b4d5870ee5584bd17029495b/](https://rutube.ru/video/122e0f05b4d5870ee5584bd17029495b/)

**Установка:**
- **Автоматически** — дать ссылку на репозиторий агенту в командной строке
- **Вручную** — запустить `install.ps1` из корня репозитория

## 🔌 MCP серверы

### 1. [mcp-bsl-platform-context](https://github.com/alkoleft/mcp-bsl-platform-context)

**Справка по встроенному языку и объектной модели** установленной платформы 1С.

**Установка:**
1. Java **17+**
2. JAR [`mcp-bsl-context-*.jar`](https://github.com/alkoleft/mcp-bsl-platform-context/releases) с Releases
3. В конфигурации MCP: `java` … `-jar` **абсолютный путь к jar** `--platform-path` **каталог установки платформы 1С**

> Подробнее в [репозитории](https://github.com/alkoleft/mcp-bsl-platform-context)

Подробно описана в проекте. Можно запустить как службу (постоянный сервер) или вручную при необходимости.

### 4. [1c_mcp](https://github.com/vladimir-kharin/1c_mcp)

**Конструктор для создания MCP на платформе 1С.** Создавайте сервера с доступом непосредственно к базе 1С — получайте данные из базы напрямую.

- Инструменты MCP пишутся **на языке 1С**
- От вас остаётся реализовать только логику

**Установка:** подробно описана в проекте

---

### 5. [1c-mcp-toolkit](https://github.com/ROCTUP/1c-mcp-toolkit)

**MCP-сервер с готовым набором инструментов** для работы с данными базы 1С. Модель может выполнить произвольный запрос или код к базе для получения и обработки данных.

> Поддерживает **анонимизацию** — полезно при использовании облачных моделей для сокрытия чувствительных данных.

**Кейсы использования:**
- 🔎 Найти в базе определённый набор данных для последующего анализа
- ❓ _"Почему тут считается так"_
- 📝 _"Как получились такие движения"_
- 📋 Анализ журнала регистрации
- 🔗 Поиск ссылок на объект
- И т.д.

**Установка:** подробно описана в проекте

---

### 6. [v8std](https://v8std.ru/mcp/)

MCP - для доступа к зеркалу v8std.ru: стандарты ИТС, диагностики (BSLLS, АПК, v8-code-style), связи между статьями, поиск и полные страницы в Markdown. 
По сути дает модели внушительное подспорье в виде знаний по 1С, которое как раз таки может эту проблематичную область знаний закрыть для большинства моделей, что как итог повысит качество ответов

Одна из интересных особенностей проекта в том, что MCP публичный и вам не нужно будет ничего настраивать у себя (но при желании можно запустить MCP и у себя - [инструкция](https://v8std.ru/support/#local-mcp))

**Установка:** Описана на странице проекта

## 📦 Прочее

### 1. [ssl_3_2](https://github.com/1c-syntax/ssl_3_2) — Библиотека стандартных подсистем, редакция 3.2

Официальная конфигурация **"Библиотека стандартных подсистем"** от **1С-Синтаксиса**. Набор универсальных функциональных подсистем для прикладных решений на платформе 1С:Предприятие 8.5.

> 💡 **Идея использования:** Открытый исходный код БСП можно использовать как базу для создания MCP с индексацией — агенты получают доступ к стандартным реализациям напрямую из библиотеки.
