### 1. [ai_rules_1c](https://github.com/comol/ai_rules_1c) — Базовый набор правил и промптов для AI-агентов

**📝 Описание**  
Обширный и переносимый набор правил, ролей субагентов и инструкций для разработки в 1С с помощью ИИ. Проект от амбассадора кодинга с ИИ на 1С — **comol**. Активно развивается и обновляется.

**🎯 Кейсы использования**  
- Автоматическая настройка контекста проекта под 1С.
- Использование специализированных субагентов (например, `1c-architect`, `1c-metadata-manager`).
- Выполнение типовых задач по готовым плейбукам (рефакторинг, создание форм, интеграции).

**✨ Особенности**  
- Поддержка множества клиентов (Cursor, Claude Code, Kilo Code и др.).
- Содержит SKILL-пакеты для управления метаданными и XML-операциями.
- > ⚠️ **Важно:** Ориентирован на использование собственных MCP-серверов от автора. Если не приобретаете их сервера — ищите аналогичные опенсорсные решения.

**⚙️ Установка**  
- **Автоматически:** Отправьте агенту команду: `Установи правила из https://github.com/comol/ai_rules_1c по AGENT-INSTALL.md`.
- **Вручную:** Запустите скрипт `install.ps1` из корня репозитория.
- 📺 [Видео-инструкция по обновлению](https://rutube.ru/video/122e0f05b4d5870ee5584bd17029495b/)

**📝 Описание**  
MCP-сервер и платформа от Upstash для подстановки актуальной, версионированной документации и примеров кода прямо в контекст AI-агента. Помогает снизить риск ответов по устаревшим данным обучения: несуществующих API, примеров для старых версий и слишком общих рекомендаций.

**🎯 Кейсы использования**  
- Получение свежей справки по внешним библиотекам, SDK и фреймворкам во время разработки.
- Уточнение API конкретной версии библиотеки, например Next.js, Supabase или Vercel AI SDK.

**✨ Особенности**  
- Работает как MCP-сервер для Cursor, Claude Code, OpenCode и других клиентов.
- Поддерживает явный паттерн запроса `use context7`, а также прямое указание ID библиотеки, например `/supabase/supabase`.
- Может пиновать версии через путь или `@version`, например `/vercel/next.js/v15.1.8` или `/vercel/next.js@v15.1.8`.

**⚙️ Установка**  
- **MCP / Cursor:** `npx ctx7 setup --cursor`
- **CLI + Skills:** используйте `ctx7 library <name> <query>` для поиска ID библиотеки и `ctx7 docs <libraryId> <query>` для получения документации.
- Node.js **18+** обязателен. API key не нужен для базовых запросов, но повышает rate limits.

### 2. [rtk](https://github.com/rtk-ai/rtk) — CLI-прокси для экономии токенов

**📝 Описание**  
Один бинарник на **Rust** (**RTK** — *Rust Token Killer*), который фильтрует и сжимает **вывод shell-команд** до того, как он попадёт в контекст LLM. Позиционируется как снижение расхода токенов примерно на **60–90%** на типичных dev-командах (git, тесты, линтеры, docker, облачные CLI и др.).

**🎯 Кейсы использования**  
- Вы часто просите агента «посмотри в терминале»: `git status` / `git diff`, прогон тестов, сборка, линтер, docker — и в чат уезжает длинный вывод команд.
- Хочется, чтобы агент опирался на факты из CLI, но без простыней логов, которые забивают контекст и удорожают сессию.

**✨ Особенности**  
- **Меньше «простыней» в ответах агента** — то, что раньше занимало тысячи токенов одним выводом команды, превращается в короткую сводку: суть сохраняется, шум убирается.
- **Спокойнее по бюджету и лимитам контекста** — в ту же сессию помещается больше полезного: обсуждение кода, правки, план, а не повторяющиеся логи.
- **Можно увидеть, сколько сэкономили** — отдельные команды показывают статистику по экономии, чтобы было понятно, окупается ли связка с вашим стилем работы.
- На **Windows** удобнее включить полный сценарий в **WSL**; без него вы по-прежнему можете пользоваться сжатием, но часть вещей придётся вызывать явно — см. README проекта.
- > ⚠️ **Важно:** если агент почти не трогает терминал, а только «читает файлы» встроенными кнопками IDE, автоматическая экономия на этих шагах **не включится** — тогда либо просите через shell, либо используйте явные команды из документации RTK.

**⚙️ Установка**  
- **Homebrew:** `brew install rtk`  
- **Скрипт / Cargo / архивы с релизов:** см. [README репозитория](https://github.com/rtk-ai/rtk#installation).  
|- После установки: `rtk init -g` (Claude Code / Copilot по умолчанию) или, например, `rtk init -g --agent cursor` для **Cursor** — затем перезапустите клиент и shell.

### 3. [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI) — Работа с Office-документами для AI-агентов

**📝 Описание**  
CLI-тулза для работы с Word, Excel и PowerPoint, заточенная **специально под AI-агентов**, а не под людей с GUI. Написана на C# (.NET 10), Apache 2.0. Один самодостаточный бинарник — не требует установленного Office, никаких зависимостей. 23k звёзд, 137 релизов, очень живой проект.

**🎯 Кейсы использования**  
- Агенту нужно сгенерировать **нормальный документ** (.docx/.xlsx/.pptx) — с таблицами, стилями, колонтитулами, а не отдавать сырой маркдаун.
- **Заполнить шаблон** договора/акта/отчёта данными из JSON.
- **Прочитать и проанализировать** Excel-файл: формулы, сводные таблицы, форматирование.
- **CI/CD-пайплайн** с Office-документами: собрать отчёт, конвертировать, разослать.
- **Сделать презентацию** по данным из 1С / API.

**✨ Особенности**  
- **Render → Look → Fix** — агент может рендернуть документ в HTML/PNG, «посмотреть» что получилось и исправить. Работает в CI/Docker/headless, где нет экрана.
- **Формульный движок Excel** — 350+ встроенных функций (LAMBDA, XIRR, динамические массивы). Excel не нужен для расчётов.
- **Round-trip Dump** — любой документ дампится в JSON, который можно «откатить» через batch. Агент учится по шаблонам.
- **Template Merge** — `{{key}}`-плейсхолдеры в docx/xlsx/pptx, замена из JSON. Нарисовал шаблон раз — наполнение дешёвое и без токенов.
- **Resident Mode** — документ висит в памяти, команды летают через named pipes (near-zero latency).
- **Live Preview** — `officecli watch deck.pptx` → браузер на localhost:26315, каждое изменение мгновенно.
- **MCP Server из коробки** — `officecli mcp claude` / `officecli mcp cursor` — сам регистрирует конфиг в редакторе.
- **SDK** — Python (`pip install officecli-sdk`) и Node.js (`npm install @officecli/sdk`).
- **Авто-детект AI-клиентов** — после установки сам раскладывает SKILL.md в Claude Code, Cursor, Copilot, Codex.

**⚙️ Установка**  
```bash
# Linux/macOS
curl -fsSL https://d.officecli.ai/install.sh | bash

# Windows (PowerShell)
irm https://d.officecli.ai/install.ps1 | iex

# Или через пакетный менеджер
brew install officecli        # macOS/Linux
scoop install officecli       # Windows
npm install -g @officecli/officecli  # любой
```

Один бинарник (~50-70 MB, .NET runtime встроен), кидается в PATH. Никакого Python, Java, Office — ноль зависимостей. Работает на Linux (x64/ARM64), macOS (Intel/ARM), Windows (x64/ARM64). После установки `officecli install` сам детектит AI-клиентов и раскладывает интеграционные файлы.
