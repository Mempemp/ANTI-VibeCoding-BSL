# ANTI-VibeCoding-BSL
Сборная солянка репозиториев, которые рекомендую к использованию для кодинга с AI-агентами в 1С и не только. (Work in progress...) 

## Правила, скилы - Как делать и с какими знаниями

### 1. [ai_rules_1c](https://github.com/comol/ai_rules_1c)

Обширный набор правил, скиллов и описаний субагентов. Репозиторий от амбассадора кодинга с ИИ на 1С comol. Репозиторий активно развивается и обновляется, но ориентирован на использование собственных MCP от comol. Если не приобретаете его MCP сервера, то необходимо искать аналогичные опенсорсные решения.

Также есть видео с инструкцией по обновлению и описанием [тык](https://rutube.ru/video/122e0f05b4d5870ee5584bd17029495b/)

Установка:
Установка достаточно простая - можно выполнить её непосредственно руками агента, дав ссылку на репозиторий в гит. Можно выполнить и вручную запустив в командной строке файл install.ps1 из корня данного репозитория

### 2. [cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills)

Большой набор навыков для AI-агентов. Описание работы с XML для корректного формирования метаданных, форм, взаимодействие с веб-публикациями агентами для тестирования и прочего. Описал бы больше как "техническое знание" по работе с метаданными в виде XML и дополнительные приспособления для автоматизации цикла разработки

## MCP

### 1. [mcp-bsl-platform-context](https://github.com/alkoleft/mcp-bsl-platform-context)

Справка по **встроенному языку и объектной модели** установленной платформы 1С.

Установка:
1. Java **17+**.
2. JAR **`mcp-bsl-context-*.jar`** с [Releases](https://github.com/alkoleft/mcp-bsl-platform-context/releases).
3. В конфигурации MCP: `java` … `-jar` **абсолютный путь к jar** `--platform-path` **каталог установки платформы 1С**. Более подробный пример в самом репо по ссылке

### 2. [rlm-tools-bsl](https://github.com/Dach-Coin/rlm-tools-bsl)

Если успростить, то данный инструмент берет на себя поиск по кодовой базе/репозиторию выдавая модели только конечный результат поиска, что позволяет избежать захламление контекста сессии и существенно сэкономить токены

Установка:
Подробно описана в проекте, можно запустить как службу, чтобы сервер крутился постоянно, но можно запускать и вручную каждый раз при необходимости

### 3. [mcp-onec-test-runner](https://github.com/alkoleft/mcp-onec-test-runner)

Инструмент для автоматизации тестирования и сборки проектов 1С:Предприятие. Подробное описание возможностей можно посмотреть тут [тык](https://github.com/alkoleft/mcp-onec-test-runner/blob/develop/docs/FEATURES.md)

Установка:
Подробно описана в проекте

### 4. [1c_mcp](https://github.com/vladimir-kharin/1c_mcp)

Инструмент - **конструктор** для создания MCP на платформе 1С. С помощью данного репозитория можно создавать MCP сервера, которые будут иметь доступ непосредственно к базе 1С, что открывает возможность получать данные непосредственно из базы. Сами инструменты MCP пишутся на языке 1С, от вас остается реализовать только их логику

Установка:
Подробно описана в проекте

### 5. [1c-mcp-toolkit](https://github.com/ROCTUP/1c-mcp-toolkit)

Описание:
MCP-сервер уже с готовым набором инструментов для работы с данными базы 1С. Модель с помощью данного инструмента может выполнить произвольный запрос или код к базе для получения и обработки данных. Также инструмент поддерживает анонимизацию, что будет полезно при использовании облачных моделей для сокрытия чуствительных данных

Кейсы использования (как минимум):
* Найти в базе определенный набор данных для последующего анализа
* "Почему тут считается так"
* "Как получились такие движения"
* Анализ журнала регистрации
* Поиск ссылок на объект
И т.д.

Установка:
Подробно описана в проекте
