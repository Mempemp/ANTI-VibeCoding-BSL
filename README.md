## 📋 Правила, скиллы и знания

### 1. [ai_rules_1c](https://github.com/comol/ai_rules_1c) — Базовый набор правил и промптов для AI-агентов

**📝 Описание**  
Обширный и переносимый набор правил, ролей субагентов и инструкций для разработки в 1С с помощью ИИ. Проект от амбассадора кодинга с ИИ на 1С — **comol**. Активно развивается и обновляется.

**🎯 Кейсы использования**  
- Автоматическая настройка контекста проекта под 1С.
- Использование специализированных субагентов (например, `1c-architect`, `1c-metadata-manager`).
- Выполнение типовых задач по готовым плейбукам (рефакторинг, создание форм, интеграции).

**✨ Особенности**  
- Поддержка множества клиентов (Cursor, Claude Code, Kilo Code и др.).
- Содержит SKILL-пакеты для управления метаданными и XML-операциями.
- > ⚠️ **Важно:** Ориентирован на использование собственных MCP-серверов от автора. Если не приобретаете их сервера — ищите аналогичные опенсорсные решения.

**⚙️ Установка**  
- **Автоматически:** Отправьте агенту команду: `Установи правила из https://github.com/comol/ai_rules_1c по AGENT-INSTALL.md`.
- **Вручную:** Запустите скрипт `install.ps1` из корня репозитория.
- 📺 [Видео-инструкция по обновлению](https://rutube.ru/video/122e0f05b4d5870ee5584bd17029495b/)

### 2. [cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills) — Навыки полного цикла разработки для AI

**📝 Описание**  
Большой набор навыков (skills) для AI-агентов (в первую очередь Claude Code), помогающий охватить весь цикл разработки на 1С:Предприятие 8.3 — от создания конфигураций до тестирования через веб-клиент.

**🎯 Кейсы использования**  
- Создание, сборка и разборка внешних обработок (EPF) и отчетов (ERF).
- Работа с XML-метаданными, генерация управляемых форм и СКД.
- Взаимодействие с веб-публикациями для автоматизированного тестирования.

**✨ Особенности**  
- Предоставляет абстракции над XML-форматами и CLI конфигуратора, позволяя модели работать с сутью задачи.
- Поддерживает автоактивацию навыков по описанию задачи.
- Совместим с открытым стандартом Agent Skills.

**⚙️ Установка**  
Скопируйте каталог `.claude/skills/` в корень проекта или используйте скрипт `switch.py` для установки под нужную платформу (Cursor, Kiro, Roo Code и др.).

### 3. [claude-code-skills-1c](https://github.com/Desko77/claude-code-skills-1c) — Набор скилов, правил и команд для Claude Code

**📝 Описание**  
Большой набор из 86 скилов, 21 правила и команд для Claude Code, ориентированных на разработку 1С:Предприятие (конфигурации, расширения, обработки, формы, запросы, базы данных и веб-тестирование).

**🎯 Кейсы использования**  
- Генерация XML-исходников (работает без платформы) и продвинутые операции, требующие 1С или MCP.
- Использование готовых стандартов кода BSL, антипаттернов и правил оптимизации запросов.
- Интеграция с BSL Language Server и другими плагинами Claude Code.

**✨ Особенности**  
- Приятная особенность — наличие отдельного класса навыков со справочниками API прикладных конфигураций (например, `zup-hr-api-reference` для 1С:ЗУП 3.1, Что является хорошим подспорьем при ИИ-разработке в ЗУП с использованием кадрового интерфейса).

**⚙️ Установка**  
Скопируйте нужные папки (`skills/`, `rules/`, `commands/`) из репозитория в соответствующие директории `~/.claude/` на вашем компьютере.

## 🔌 MCP серверы

### 1. [mcp-bsl-platform-context](https://github.com/alkoleft/mcp-bsl-platform-context) — Справка по встроенному языку 1С

**📝 Описание**  
MCP-сервер, предоставляющий AI-агентам контекстную справку по встроенному языку и объектной модели установленной платформы 1С.

**🎯 Кейсы использования**  
- Получение точного синтаксиса методов и свойств объектов платформы прямо во время написания кода.
- Изучение доступных функций платформы без необходимости гуглить.

**✨ Особенности**  
- Работает локально и опирается на файлы установленной платформы 1С.

**⚙️ Установка**  
1. Убедитесь, что установлена Java **17+**.
2. Скачайте JAR-файл `mcp-bsl-context-*.jar` из релизов репозитория.
3. В конфигурации MCP пропишите команду: `java -jar <абсолютный путь к jar> --platform-path <каталог установки платформы 1С>`.

### 4. [1c_mcp](https://github.com/vladimir-kharin/1c_mcp) — Конструктор MCP-серверов на платформе 1С

**📝 Описание**  
Инструмент (расширение 1С) для создания собственных MCP-серверов непосредственно на платформе 1С:Предприятие. Берет на себя всю техническую рутину протокола MCP.

**🎯 Кейсы использования**  
- Разработка кастомных инструментов для AI-агентов, которым нужен прямой доступ к данным и бизнес-логике конкретной базы 1С.

**✨ Особенности**  
- Инструменты MCP пишутся **на языке 1С** — от вас остаётся реализовать только логику.
- Есть Python-прокси для решения проблем с аутентификацией и транспортом (stdio).

**⚙️ Установка**  
Подключите готовое расширение `MCP_Сервер.cfe`, опубликуйте HTTP-сервис и настройте подключение AI-клиента (напрямую или через Python-прокси). Подробности в репозитории.

### 5. [1c-mcp-toolkit](https://github.com/ROCTUP/1c-mcp-toolkit) — Готовый набор инструментов для работы с БД 1С

**📝 Описание**  
Система интеграции AI-агентов с базами данных 1С через MCP и REST API. Предоставляет готовый набор инструментов "из коробки" без необходимости программирования.

**🎯 Кейсы использования**  
- 🔎 Выполнение произвольных запросов к БД для анализа данных.
- 📋 Получение и анализ записей журнала регистрации.
- 🔗 Поиск ссылок на объекты и получение метаданных.
- ❓ Ответы на вопросы вида _"Почему тут считается так"_ или _"Как получились такие движения"_.

**✨ Особенности**  
- Работает как встроенный сервер прямо в обработке 1С (без Python) или через прокси.
- Не требует изменения конфигурации и публикации базы.
- Поддерживает **анонимизацию** — полезно при использовании облачных моделей для сокрытия чувствительных данных.

**⚙️ Установка**  
Скачайте обработку `MCP_Toolkit.epf`, откройте в 1С и запустите встроенный сервер. Альтернативно — разверните прокси через Docker.

### 6. [v8std](https://v8std.ru/mcp/) — База стандартов и диагностик 1С

**📝 Описание**  
MCP-сервер для доступа к зеркалу v8std.ru: стандарты ИТС, диагностики (BSLLS, АПК, v8-code-style), связи между статьями и поиск.

**🎯 Кейсы использования**  
- Проверка кода на соответствие стандартам 1С.
- Получение объяснений по предупреждениям анализаторов кода.
- Поиск стандартов по фрагменту кода или тексту ошибки.

**✨ Особенности**  
- Дает модели внушительное подспорье в виде знаний по 1С, повышая качество ответов и снижая галлюцинации.
- Публичный MCP — не нужно ничего настраивать у себя (но есть возможность локального запуска для закрытого кода).

**⚙️ Установка**  
Добавьте URL `https://ai.v8std.ru/mcp` в конфигурационный файл MCP вашего AI-клиента (например, `.cursor/mcp.json`).

## 📦 Прочее

### 1. [ssl_3_2](https://github.com/1c-syntax/ssl_3_2) — Библиотека стандартных подсистем (БСП)

**📝 Описание**  
Официальная конфигурация **"Библиотека стандартных подсистем"** редакции 3.2 от **1С-Синтаксиса**. Набор универсальных функциональных подсистем для прикладных решений на платформе 1С:Предприятие 8.3.

**🎯 Кейсы использования**  
- Изучение эталонного кода и архитектурных решений от 1С.
- > 💡 **Идея использования:** Открытый исходный код БСП можно использовать как базу для создания MCP с индексацией — агенты получают доступ к стандартным реализациям напрямую из библиотеки, чтобы "не изобретать велосипед".

**✨ Особенности**  
- Содержит актуальный код БСП в виде выгруженных исходников.

**⚙️ Установка**  
Клонируйте репозиторий и настройте индексацию папки в вашем AI-клиенте.
